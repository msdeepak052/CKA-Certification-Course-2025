# **Allowed Tools & Resources for CKA & CKAD Exams**

During the **Certified Kubernetes Administrator (CKA)** and **Certified Kubernetes Application Developer (CKAD)** exams, candidates are permitted to use specific tools and documentation under strict conditions.

### **General Rules**

* All resources must be accessed **only from within the exam VM (Linux environment)**.
* Usage must be **independent** — no third-party help, collaboration, or external research.
* Only the **approved documentation and links** listed below are allowed.

---

## **Permitted Resources**

### **1. Official Kubernetes Documentation**

* [https://kubernetes.io/docs](https://kubernetes.io/docs)
* You are allowed to:

  * Use the **search function within the site**
* You are **NOT allowed to**:

  * Open or navigate to **external search results**

---

### **2. Kubernetes Blog**

* [https://kubernetes.io/blog](https://kubernetes.io/blog)
* Can be used for additional context or examples (within allowed scope)

---

### **3. Helm Documentation**

* [https://helm.sh/docs](https://helm.sh/docs)
* Useful for tasks involving Helm charts and package management

---

### **4. Exam Interface – Quick Reference**

* Built-in **Quick Reference box** inside the exam environment
* Includes:

  * Task-specific documentation links
  * References to tools required for solving exam questions

---

### **5. (CKA Only) Gateway API Documentation**

* [https://gateway-api.sigs.k8s.io](https://gateway-api.sigs.k8s.io)
* Applicable **only for CKA exam candidates**

---

## **Important Restrictions**

* ❌ No external websites (Google, Stack Overflow, GitHub, etc.)
* ❌ No communication tools or external assistance
* ❌ No opening links outside the allowed domains
